# 赛博抽抽机 🎲📺

一台浮在桌面上的复古像素小电视，是个万能随机决定器兼桌宠：拧旋钮换台，可以求签、决定中午吃什么、跑个番茄钟、或抽任何你自定义的选项。点一下唰唰唰滚动，定格出结果。待机时屏幕显示可爱的颜文字表情 `・ω・`，闲久了还会犯困、睡着。

> 下载安装（推荐）：前往 [**Releases**](https://github.com/Little-077/cyber-fortune-tv/releases) 下载最新版 —— macOS 用 `.dmg`，Windows 用 `.exe`。
> macOS（Apple 芯片）首次打开：**右键图标 → 打开**（已 ad-hoc 签名，不会再报「已损坏」）。

## 功能

**抽选频道**
- **求签**：7 级加权（大吉 / 吉 / 小吉 / 末吉 / 平 / 凶 / 小凶），每次随机配一句签文
- **中午吃什么**：内置的选择困难急救频道
- **自定义列表**：从你自己的选项里抽一个；可在设置里增删频道、编辑选项与结语
- **每个选项可调权重**：选项前加 `+` / `++` 提高出现概率（偏爱），加 `-` / `--` 降低（冷门）

**番茄钟频道** 🍅
- 侧边按钮一键开始 / 暂停；开始时全屏显示 3 秒，再自动缩到角落的迷你倒计时条
- 计时结束整机蹦跳庆祝 + 音效
- 与其它频道、Claude 状态可并存（倒计时自动挪到顶部迷你条）

**Claude Code 状态联动** 🤖
- 接入 Claude Code 后，小电视会实时显示当前状态：
  - **工作中** = 屏幕上像素铅笔唰唰写字
  - **等你确认** = 像素眼睛左右看
  - **完成** = 开心颜文字 `＾▽＾` + ✓ + 撒星星 + 蹦跳
- **暂停 / 打断时**：约 6 秒无动作铅笔会**停笔**，约 20 秒自动**收笔回到待机**，不会一直写个不停

**换台 / 换肤（电视右侧两个旋钮）**
- 上旋钮 = 换台（循环切换频道，屏幕顶部显示频道名，切台有雪花效果）
- 下旋钮 = 换肤（7 套预设主题，整机配色实时切换）

**桌宠情绪**
- 待机久了会犯困、进入睡眠（屏幕变暗、天线打盹）；有动作或来活了就醒

**设置面板**（hover 右上角 ⚙ 打开，共四个标签页）
- **频道**：新建 / 删除频道、编辑选项列表与结语
- **专注**：番茄钟时长等
- **外观**：选主题，或 **DIY 自定义主题**（自己配色）
- **通用**：🌐 **中英文切换**、开机自启开关、当前版本号
- 所有设置都会**持久化**保存，下次打开记住

**外观与交互**
- 复古 CRT + 像素风：扫描线 / 暗角 / 玻璃高光 / 雪花噪点 / 定格闪光 + 8-bit 音效
- **透明 + 无边框 + 总是置顶**，像桌宠一样浮在桌面、跨所有桌面空间可见
- 滚轮缩放整机；上下拖动天线可伸缩；拖动机身移动窗口
- 支持**开机自动启动**

## 两种运行方式

### 1) 直接下载安装（推荐）

前往 [Releases](https://github.com/Little-077/cyber-fortune-tv/releases) 下载对应系统的安装包即可，无需 Node 环境。

- macOS：`.dmg`，拖进「应用程序」，首次**右键 → 打开**
- Windows：`.exe`，按提示安装

### 2) 从源码运行（开发 / 想改代码）

需要 Node。本机没装可用 Homebrew 安装：

```bash
brew install node
```

然后在项目目录：

```bash
npm install        # 安装 Electron（首次约几十 MB）
npm start          # 启动桌面应用
```

启动后小电视会出现在主屏幕右下角。

- 点击屏幕 / 红色电源键 / 空格键 = 抽一签
- 拖动电视机身 = 移动窗口
- 鼠标移上去，右上角 ✕ = 关闭（或 `Cmd + Q`）

## 交互一览

| 操作 | 效果 |
|------|------|
| 点屏幕 / 空格 / 回车 | 抽一下；出结果后再点 = 再抽一次 |
| 点电源键（待机时）| 抽一下 |
| 点电源键（出结果后，灯变蓝时）| 复位回颜文字待机 |
| 拧上旋钮 | 换台（切换频道）|
| 拧下旋钮 | 换肤（切换主题）|
| 侧边按钮（番茄钟频道）| 开始 / 暂停计时 |
| hover → ⚙ | 打开设置（频道 / 专注 / 外观 / 通用）|
| 在电视上滚动鼠标滚轮 | 整机缩放（上滚放大 / 下滚缩小）|
| 上下拖动天线 | 拉长 / 缩短天线（向上拉变长，窗口随之长高）|
| 拖动机身 | 移动窗口 |
| hover → ✕ / Cmd+Q | 退出 |

> 🥚 隐藏彩蛋：天线可以拉长，拉满还有隐藏效果哦～

## 接入 Claude Code 状态（可选）

小电视内置一个本地状态服务（`127.0.0.1:51789`）。在 Claude Code 的 `~/.claude/settings.json` 里加 hooks，用 `curl` 通知它当前状态即可：

- 开始 / 进行中 → `curl -s -m 2 http://127.0.0.1:51789/working`
- 完成 → `curl -s -m 2 http://127.0.0.1:51789/done`
- 等待确认 → `curl -s -m 2 http://127.0.0.1:51789/waiting`

（分别挂在 `UserPromptSubmit` / `PreToolUse` / `PostToolUse` → working，`Stop` → done，`Notification` → waiting 上。）

## 项目结构

```
src/
  main.js        Electron 主进程：透明置顶窗口、缩放贴合、配置读写、设置窗口、状态服务、开机自启
  preload.js     安全桥接：退出 / 缩放 / 配置 / 打开设置 / 状态
  data.js        共享数据：主题、求签签库、默认频道、中英文文案
  index.html     电视结构
  style.css      像素 CRT 外观、主题变量、动画（写字笔 / 眼睛 / 番茄钟 / 蹦跳等）
  renderer.js    频道/主题/抽选逻辑、动态权重、番茄钟、情绪、Claude 状态、滚动动画、天线、音效
  settings.html / settings.css / settings.js   设置面板（四个标签页 + 中英文）
  icon.png       运行时 Dock 图标
build/
  afterPack.js   打包后对 mac 应用做 ad-hoc 签名
.github/workflows/build.yml   打 tag 自动出 mac dmg + win exe 并发布 Release
```

配置文件保存在 `~/Library/Application Support/赛博抽抽机/config.json`。

---

想改默认主题 / 签库 / 默认频道 / 文案，编辑 `src/data.js`。日常增删频道与选项、切主题、切语言，直接用应用内 ⚙ 设置面板即可。
